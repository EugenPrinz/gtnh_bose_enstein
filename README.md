# BEC — автоматизация линии конденсата Бозе-Эйнштейна (GTNH)

Программа для OpenComputers, которая будет вести **линию BEC** в GTNH 2.9.1: одна Матрица наблюдения,
до 16 узлов телепортации, заказы — автокрафтом из основной ME-сети. Цель — одна программа на всю игру:
любые рецепты BEC, любые тиры нанитов, новые рецепты из обновлений без правки кода.

**Статус:** этап 1 готов — модель и потиковый симулятор линии на Lua 5.3, сверенные друг с другом тестами.
Дальше — HAL (`hal/`, `becctl probe`) и запуск в креативе.

Механика сверена с исходниками `GTNewHorizons/GT5-Unofficial`, тег `5.09.54.275` (это GT5U в GTNH 2.9.1):
`MTEBECGenerator`, `MTEBECStorage`, `MTEBECDiode`, `MTEBECAssembler`, `MTEBECIONode`, `BECStructureDefinitions`,
`CondensateType`, `BECRecipes`.

## Коротко о линии

- **Аппарат квантового запутывания** превращает исходные жидкости в запутанный конденсат. Ускоряется только
  энергией — это **главное узкое место**: партия собирается секунды, запутывается десятки минут. Конденсат держат в запасе.
- **Поле удержания** — единственное хранилище конденсата (1 L = 1 EU/t). **Любая остановка стирает всё.**
- **Затвор Максвелла** — однонаправленный фильтр между сетями: правая (сборка) видит левую (хранение) только
  через фильтр. Без него в Матрицу попадают чужие конденсаты: каждый замедляет крафт, больше 3 — рецепт теряется.
- **Матрица наблюдения** раздаёт энергию, конденсат и наниты узлам по лучам прямой видимости (до 128 блоков).
- **Узлы телепортации** собирают. Скорость — только от нанитов: N / (P · 2^Δтир · загрязнители).
  Наниты в шине **не расходуются**.

## Решения

- Одна линия, до 16 узлов; заказы — автокрафт ME.
- AE2 — по схеме [Armisael5/gtnh-bec-controller](https://github.com/Armisael5/gtnh-bec-controller):
  Pending-подсеть с челноком ячеек, Input → узлы через беспроводные коннекторы, наниты — фейковый крафт
  + извлечение IO Port/Transposer.
- Стойка OC с сервером и Component Bus (≈ 29 компонентов).
